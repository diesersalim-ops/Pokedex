# Pokedex

Small Pokédex built with HTML, CSS and JavaScript, no framework, no build step. All data comes from the [PokéAPI](https://pokeapi.co): the list is loaded in steps of 20 Pokémon (lazy loading), the search works over all Pokémon, and the evolution chain is loaded when its tab is opened.

How to open: double-click `index.html` (internet connection needed).

Structure: `index.html`, `style.css` (imports `styles/`), `script.js` (logic), `scripts/db.js` (state), `scripts/template.js` (HTML templates).
