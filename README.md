# Pokedex

Small Pokédex built with HTML, CSS and JavaScript, no framework, no build step. It shows the first 151 Pokémon from a Firebase Realtime Database, with search, a detail view and evolution chains from PokéAPI.

How to open: double-click `index.html` (internet connection needed).

Structure: `index.html`, `style.css` (imports `styles/`), `script.js` (logic), `scripts/db.js` (state), `scripts/template.js` (HTML templates). `data/pokemon-import.json` was only used once to fill the database.
